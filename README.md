# Miga y Miel

Sitio educativo de una panadería artesanal ficticia, desarrollado con HTML5, CSS3 y JavaScript.

## Contenido

- Inicio, Nosotros, Productos, Galería y Contacto.
- Seis ilustraciones SVG originales.
- Filtros de productos, menú móvil y formulario con validación local.

## Abrir localmente

Abre `index.html` en un navegador. Todos los recursos se incluyen en el proyecto.

## GitHub Pages

Este proyecto está preparado para publicarse desde la raíz de la rama `main`:

1. Subir el contenido de esta carpeta al repositorio, con `index.html` en la raíz.
2. En **Settings → Pages**, elegir **Deploy from a branch**.
3. Seleccionar **main** y **/ (root)** y guardar.
4. Esperar a que GitHub termine la publicación y usar la dirección que indique Pages.

El archivo `.nojekyll` permite servir los archivos estáticos sin procesamiento de Jekyll. Las rutas relativas admiten la publicación bajo el nombre del repositorio.

## Alcance

Marca, precios y contacto son de demostración. El formulario no envía ni guarda datos. No se requiere un dominio propio ni configurar servicios externos para las interacciones locales.
